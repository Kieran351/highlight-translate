# MVP 验收记录

日期：2026-08-09
环境：macOS、Chrome、Manifest V3 解压扩展

## 自动化验证

以下命令均在仓库根目录执行：

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

`npm run build` 还会执行安全检查，确认 Manifest V3 入口存在、权限和主机范围符合规格，并扫描源码及构建产物中的疑似 API Key 与调试日志。

## 真实 Chrome 验收

- 从 `dist/` 成功加载扩展；首次安装自动打开设置页，重新加载扩展不会重复打开；工具栏扩展菜单点击后直接进入设置页。
- 设置页保存后只显示掩码；保存和测试连接是两个独立操作；清除后英文选区显示“请先配置 API Key”。
- 正常中文选区显示触发按钮和本地原文卡片，无需 API Key。
- 纯 URL、纯邮箱不显示触发按钮；可编辑文本框中的选区不显示触发按钮；5,001 字符选区显示本地长度错误，不发起翻译。
- 英文选区显示“英语 → 简体中文”；无 Key 时复制按钮不可用，并提供设置入口。
- 用户随后仅在本机 Chrome 设置页配置真实 Key；设置页“测试连接”和英文选区远程请求均返回经归一化的“网络连接失败”，界面未泄露 Key、选区或原始响应。
- 中文为主的混合选区显示“中文”并原样保留外文；未知短文本显示“自动检测 → 简体中文”。
- 中文结果可以复制，界面显示“已复制”反馈。
- 页面滚动离开选区时卡片隐藏，滚回后恢复同一结果。
- 在 800 × 600 视口及长、多行选区下，触发按钮跟随选区末端，卡片保持在视口内；恢复视口后定位正常。
- 从右向左反向拖选中文句子时，按钮锚定在鼠标释放一侧，点击后卡片从同一锚点展开。
- 强制深色系统偏好后卡片切换为深色，宿主页面仍为浅色；恢复偏好后不保留测试覆盖。
- `Esc` 和页面空白处可以关闭卡片；连续选区、取消竞态及过期结果隔离由协议测试覆盖。
- 扩展管理页未显示扩展错误；测试页控制台未出现本扩展的未处理错误。

## 验收边界

真实 DeepSeek API Key 只由用户输入本机 Chrome，未进入聊天、仓库、日志或测试工具。真实服务的成功流式翻译仍未完成：Chrome 扩展请求得到归一化网络错误，而不携带 Key 的终端连通性检查返回 `401`，证明官方主机可达。流式成功、SSE 分片、取消、过期结果隔离、三类超时、错误归一化、部分结果与重试由可替换的 Provider、Chrome API 和时钟自动化测试覆盖。
